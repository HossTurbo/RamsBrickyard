# Ramalepe Brickyard — GitHub Pages version

This is the standalone static version of the Ramalepe Brickyard website. It does not require ChatGPT hosting.

## Publish on GitHub Pages
1. Create a new GitHub repository, for example `ramalepe-brickyard`.
2. Upload **everything inside this folder** to the root of the repository (`index.html`, `styles.css`, `app.js`, `.nojekyll`, and the `assets` folder).
3. In the repository open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. GitHub will provide a public `github.io` address.

## Custom domain
A custom domain such as `ramalepebrickyard.co.za` can be connected later from GitHub Pages settings and your domain provider's DNS settings.
